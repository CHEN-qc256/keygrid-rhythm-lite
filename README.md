# KeyGrid Rhythm · 九宫格数字键音游

> 用键盘上排成九宫格的数字键弹奏乐曲 —— 屏幕中央是一块 3×3 的九宫格，**格子就是琴键**，
> 音符从各自格子的顶边落下，落到格内的判定线时按下对应的数字键。

**纵向 = 音高，横向 = 声部**，九个格子按五声音阶映射到 C4–G5，所以乱按也不会难听。

```
   7(D5)   8(E5)   9(G5)      ← 高音区
   4(G4)   5(A4)   6(C5)      ← 中音区
   1(C4)   2(D4)   3(E4)      ← 低音区
```

主键盘备选键：`U I O` / `J K L` / `M , .`（两张表同时生效，键位可以在设置里逐格改）。

## 下载与运行

到本仓库的 [**Releases**](../../releases/latest) 页面下载（本仓库只放说明，运行包挂在 Release 附件里）：

| 附件 | 内容 | 大小级别 |
|------|------|----------|
| `KeyGrid-Rhythm-v0.84-win64.zip` | `KeyGrid Rhythm.exe` + `KeyGrid Rhythm.pck` + 使用说明 | 约 100 MB |
| `mp4-to-ogv-tools.zip` | 视频转码小工具（`ffmpeg` + 图形界面），**想自己导入 mp4 背景视频才需要** | 约 160 MB |

解压后：

1. **`KeyGrid Rhythm.exe` 和 `KeyGrid Rhythm.pck` 必须放在同一个文件夹里**（exe 靠它旁边的 pck 取资源，只拷 exe 会起不来）。
2. 双击 `KeyGrid Rhythm.exe` 即可，无需安装。
3. 系统要求：Windows 64 位。★ **解压到能写的目录**（桌面、D 盘自建文件夹都行）；放进
   `C:\Program Files` 这类需要管理员权限的目录，「导入视频」这一步会写不进去（它要往 exe 旁边落文件）。

> ★ **本包不含任何音乐 / 视频素材**（见下面的「素材与许可」）。自带的两份教程谱面是**无声**的，
> 想听歌、想看背景视频，请看「自己导入音乐」一节。

## 第一次打开：延迟校准

不同机器的音频输出延迟不一样，换一台电脑常常会觉得「**敲击与方块下落不同步**」。
v0.83 起第一次启动会**自动弹出校准页**：

- 跟着九宫格**闪光的那一下**敲（有节拍器声，默认 120 BPM），敲满 **16 下**；
- `回车` 保存，`Esc`「稍后再说」、`R` 重来；
- 存好之后**每次启动都按这个偏移判**，不再自动弹；想重来就去 **设置 → 延迟校准**
  （按「恢复默认」会连校准一起清掉，下次启动重新问）。

打歌时也能用 `-` `=` 临时调 ±5 ms（不落盘）。

## 操作

| 键 | 作用 |
|----|------|
| 小键盘 `1`–`9`（或 `U I O` / `J K L` / `M , .`） | 弹奏 |
| `空格` | 开始 / 再来一局 / 确认 |
| `Tab` | 拉出 / 收起左侧曲目列表（鼠标也能点左边那块窄标签） |
| `↑` `↓` / `W` `S` | 在列表里上下选（到头会绕回去） |
| `回车` / 小键盘回车 | 确认选曲 |
| `右键` | 曲目行菜单：重命名 / 删除（只有自己导入的谱面能改能删） |
| `R` / `Delete` | 改名 / 删除当前高亮那一行 |
| `C` | 换到曲目库里的下一份谱面 |
| `Esc` | 打歌中 = 暂停卡片；待机或结算后 = 回开始菜单 |
| `F2` | 「制作谱面」菜单（制作谱面 / 导入视频）；屏幕右边缘那条竖标签等价于按 `F2` |
| `F3` | 换一档按键音并当场敲一声（③静音 / ④打击音 / ⑫真实音高 / ⑬短切片） |
| `F4` `F5` | 按键音总音量 −1.5 dB / +1.5 dB |
| `F1` | 显示 / 隐藏调试面板（默认隐藏） |
| `F6`–`F10` | 九宫格动效预览（打歌中也能按） |

**开始菜单**（启动即见）：开始游戏 / 新建存档 / 加载存档 / 设置 / 退出游戏，`↑` `↓` 选、`回车` 确认。
**设置页**里能调主音量 / 音乐音量 / 按键音音量 / **九宫格透明度**（出厂默认 **50%**）/
分辨率 / 全屏 / 九宫格动效 / **键位** / **延迟校准**。设置存在 `user://settings.cfg`，成绩存在 `user://save.json`。

## 自带的谱面 / 自己导入音乐

自带两份教程谱面（`练习曲 · 慢慢来`、`教程曲 · 三十三键`），**都是无声的**，用来熟悉下落与判定。

想加自己的歌：

1. 按 `F2` 打开「制作谱面」菜单；
2. **制作谱面** —— 选一个 `MP3 / OGG / WAV`，游戏会自动分析节拍与音高，生成一份谱面（难度可选）；
3. **导入视频**（可选）—— 给已有谱面配一段背景视频调延迟。视频**只能是 `.ogv`（Theora）**，
   mp4 要先转：把 `mp4-to-ogv-tools.zip` **解压到游戏目录**（得到 `<游戏目录>\tools\mp4-to-ogv\`，
   游戏就按这个位置找它），然后把 mp4 拖进那个小窗口即可（也可以直接把 `.ogv` 放进
   `<游戏目录>/videos/`，谱面里写 `game://videos/文件名.ogv`）。

谱面是纯 JSON，自动生成的谱面存在游戏自己的数据目录
（`%APPDATA%\Godot\app_userdata\KeyGrid Rhythm\charts\`）里，用「右键 → 重命名 / 删除」管理
（只有自己导入的能改能删）。★ 想用手写的谱面：把它放进 `<游戏目录>\charts\`，曲库会一起列出来。
★ 提示：如果导入视频那一步报错，多半是游戏放在了不可写的目录（见上面「下载与运行」第 3 条）。
没有写背景视频的谱面会用**纯深色背景**；通用版里还会从内置的随机视频池里挑一段来放。

## 常见问题

- **双击没反应 / 报错找不到资源**：`KeyGrid Rhythm.pck` 没和 exe 放在一起。
- **没声音**：本包**不含音乐**，自带的谱面本来就是无声的；导入自己的歌听。
- **敲击与下落不同步**：走一遍「设置 → 延迟校准」（第一次启动会自动弹）。
- **导入视频 / 谱面失败**：游戏所在目录不可写，换一个自己有权写入的目录解压。
- **想看炫一点的画面**：把「九宫格透明度」调低，背景视频才看得清。
